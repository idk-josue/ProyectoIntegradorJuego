# 🎮 Proyecto Integrador: Tres en Raya

**Universidad:** Universidad Internacional del Ecuador (UIDE)  
**Asignaturas:** Lógica de Programación, Introducción a Redes, Arquitectura de Computadoras, Ingenieria y Pensamiento Humano y Effective Communication  
**Nivel:** Primer nivel  
**Fase:** 3 de 6 – Entorno de trabajo  
**Lenguaje:** Python

---

## 1. Descripción del proyecto

El proyecto trata en el desarrollo de un videojuego de Tres en Raya utilizando el lenguaje de programación de Python.

El objetivo es aplicar todos los conocimientos adquiridos en las diferentes asignaturas. 

El desarrollo se realiza por fases, utilizando RAPTOR para el diseño inicial de los algoritmos y Python para su posterior implementación.

En esta tercera fase se desarrolla la estructura inicial del programa, incluyendo el menú principal, la validación de las jugadas y la determinación del resultado de la partida.

## 4. Descripción de los archivos

| Archivo | Función |
|---|---|
| juego.py | Contiene el menú principal del videojuego. |
| game_logic.py | Contiene la lógica de validación de las jugadas y la determinación del resultado de la partida. |
| server.py | Archivo reservado para implementar el servidor correspondiente al Jugador 1. |
| client.py | Archivo reservado para implementar el cliente correspondiente al Jugador 2. |
| diseno/ | Contiene los diagramas de flujo realizados en RAPTOR durante la Fase 2. |

## 5. Requisitos para ejecutar el proyecto

Para ejecutar el proyecto se necesita:

- Visual Studio Code
- Los archivos del repositorio descargados en el equipo.
